Conceito
O escopo é o que será feito no projeto, descrição detalhada dos
produtos e serviços a serem gerados para atender os objetivos do
projeto.

O que é a declaração de escopo do projeto?
• Descreve as entregas e o trabalho necessário para cria-las.
• Apresenta prazos, custos, atividades e fases do desenvolvimento.
• Contém exclusões explícitas do escopo que podem auxiliar o
gerenciamento das expectativas das partes interessadas.
• O escopo e a EAP1 serão base para a organização e monitoramento do
projeto;
• Cada pacote de trabalho (EAP) deve descrever atividades necessárias para
sua execução (PRAZO) e recursos necessários para determinar o
orçamento do projeto (CUSTO).

3. Objetivos SMART e critérios de sucesso do projeto
4. Descrição do Projeto
Specific (específico)
5. Exclusões do Projeto (fora do escopo) Measurable (medição)
Assignable (quem)
6. Restrições
Realistic (realístico)
7. Premissas
Time-related (quando)
8. Estrutura Analítica do Projeto (entregáveis)
9. Planejamento Preliminar (cronograma) SM A R T
10.Descritivo de Custos e Fluxo de Pagamento

Objetivos SMART
Específico: O que exatamente precisa ser feito
Mensurável: Progresso pode ser medido
Alcançável: objetivos aceitos por quem vai realiza-los
Realista: objetivos são possíveis
Cronometrado: tempo para realização é claro
