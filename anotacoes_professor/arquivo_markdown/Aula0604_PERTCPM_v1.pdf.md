Método do Caminho Crítico
• O método do caminho crítico (Critical Path Method) é
uma técnica de gestão do projeto passo a passo para
identificação de atividades no caminho crítico.
• É uma abordagem de planejamento que divide o
projeto em várias tarefas, exibe-os em um gráfico de
fluxo (PERT) e calcula a duração do projeto com base
na duração estimada para cada tarefa.
• O método identifica as tarefas
que são essenciais para a
conclusão do projeto, de acordo
com tempo de cada uma.

A equipe que criou este método lhe deu o nome de Técnica

PERT e CPM
CPM e PERT são parecidos, mas usam técnicas
diferentes para calcular a duração de tarefas.
PERT usava três estimativas de tempo diferentes para a
duração de cada projeto e calculava a probabilidade de
conclusão do projeto a qualquer hora.
CPM usava duração única para cada tarefa; preocupava-
se, não somente com o tempo de conclusão do projeto
mas também com a análise de custos extras que seriam
acumulados caso a duração do projeto fosse reduzida.
Atualmente os termos CPM e PERT são usados para
indicar o uso da análise do caminho crítico, sem as
diferenciações na forma de cálculo.

Método do Caminho Crítico
Benefícios para o GP
Tarefas mais importantes: Identifica claramente as
tarefas as quais você precisa dar maior atenção. Caso
qualquer tarefa demore mais do que o tempo estimado,
comece ou termine mais tarde que o planejado, o seu
projeto inteiro será negativamente afetado.
Reduzir a duração de projetos: Depois da análise de
tempo inicial, tarefas no caminho crítico podem ser melhor
exploradas para reduzir o tempo.
A visualização gráfica (Gantt), permite observar cada
tarefa a ser modificada e quais tarefas devem permanecer
inalteradas.

Método do Caminho Crítico
Compara o que foi planejado com o progresso real:
Um cronograma de base (baseline) é criado a partir da
análise do caminho crítico inicial para acompanhar o
progresso programado.
Ao longo do projeto, um gerente pode identificar as tarefas
que já foram finalizadas de modo a estimar o tempo
restante do projeto.
Ajustes podem ser feitos nos prazos das tarefas
subsequentes a partir do histórico das anteriores (lessons
learned).

Construção de uma rede PERT/CPM
• Crie uma lista das atividades que serão realizadas na
execução do projeto.
• Nomeie cada atividade com uma letra do alfabeto.
• Defina o tempo para a realização de cada atividade.
• Elabore um quadro especificando as atividades pela
ordem de prioridade.
• Elabore a rede de Petri, o qual será a representação
gráfica da sequência lógica entre as atividades e
aquelas que ocorrem paralelamente.
• Faça uma lista de eventos, especificando o início e fim
de cada atividade.
• Faça um quadro indicado os eventos prioritários.
• Com a rede PERT CPM pronta, determine o tempo mais
cedo e o tempo tarde para a execução do projeto.
• Encontre o caminho crítico da rede PERT CPM. 16
