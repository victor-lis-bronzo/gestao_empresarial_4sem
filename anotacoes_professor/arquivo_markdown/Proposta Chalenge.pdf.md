3. DESCRIÇÃO DOS SERVIÇOS

Conforme  mencionado  no  item  2,  entendemos  que  as  atividades  relacionadas  ao
processamento  da  pesquisa  CHALENGE
tem  dois  aspectos  diferentes,  porém
interdependentes.

O  objetivo  final  de  todo  o  trabalho  é  o  processamento  dos  dados  captados  pelos
pesquisadores  e  sua  transformação  em  ferramentas  de  análise  estratégica  para  os
patrocinadores da pesquisa (relatórios e gráficos com os resultados voltados para os focos
da pesquisa). O uso de tecnologia para esse processamento busca otimização e redução de
tempo e custos para a obtenção desse objetivo final.

Assim, descreveremos as atividades contempladas nesta proposta para o processamento da
pesquisa  sob  o  enfoque  principal  do  tratamento  e  compilação  dos  dados  captados  e  as
atividades de apoio técnico voltados para a otimização de cada procedimento.

Além das atividades previstas no item 3, esta proposta abrange:

✓  Ambiente para Processamento

O  processamento  será  feito  utilizando-se  o  sistema  CHALENGE  de  propriedade  do
TABAJARA,  em  ambiente  NT  com  SGBD  Sybase.  A  linguagem  utilizada  para
desenvolvimento dos aplicativos é Visual Basic, e os gráficos são produzidos em Excel
e Power Point.

O sistema atual contempla a entrada dos questionários, cálculos e emissão dos resultados.

Esta proposta contempla alterações no sistema para adequar os aplicativos para atender
a pesquisa em andamento.

✓  Resultados

Os  resultados  serão  fornecidos  obedecendo  a  estrutura  geográfica  do  TABAJARA:
Country Results, Region e Sector.
