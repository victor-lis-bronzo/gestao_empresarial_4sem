# Considerações Iniciais

## Cenário Atual

Descrever a situação atual do processo ao qual o sistema vai fazer parte ou substituir.

## Justificativa do Projeto

Conforme o cenário atual descrito, esclarecer os benefícios e motivadores que levaram a adoção de um sistema informatizado ou a substituição de algum existente. Explorar os benefícios a serem alcançados com a nova sistemática.

# Critérios de Sucesso

Elencar tópicos que contribuam para o sucesso do projeto como colaboração próxima do usuário final, apoio da gestão da organização objeto da implantação.

# Descrição do Projeto

Descrever o melhor possível a solução proposta com tópicos e subtópicos, figuras diagramas e rascunhos de interface.

### topico

# Não Abrangência do Projeto

Descrever o que o projeto não vai contemplar. Itens que podem parece implícitos como manutenção do sistema depois de implantado, treinamento de usuários (se for o caso), migração de dados legados, popular o banco de dados, etc.

# Restrições

Descrever alguma limitação que porventura exista como prazo, recursos limitados, falta de algum equipamento, uso de simuladores, etc.

# Premissas

Descrever acordos e conceitos presumidos ou fornecidos de terceiros. Pode incluir a tecnologia a ser utilizada (aplicativo web/mobile/desktop, linguagem de programação, banco de dados, etc.).

# Planejamento Preliminar

Incluir etapas iniciais previstas para o projeto. Ao longo do tempo será atualizado com planejamento mais efetivo.
